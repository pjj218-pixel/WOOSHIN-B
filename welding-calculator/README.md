# 용접 생산기술 계산기 (PySide6)

## 새 화면 실행

Windows에서 이 폴더의 `용접계산기_실행.cmd`를 더블클릭합니다. 처음 실행하기 전에는 PowerShell에서 다음 명령으로 작업 폴더 전용 환경과 패키지를 설치합니다.

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe qt_app.py
```

새 화면은 `작업 조건`, `결과`, `사내 승인 조건`, `와이어 사용량`, `실측 검증`의 다섯 메뉴를 사용합니다. 기존 Python 계산 모듈과 CSV 형식은 그대로 사용합니다. 차종·제품명과 제품 형상 이미지는 로컬 화면에서만 처리하며, 이미지 자동 판독이나 외부 업로드는 하지 않습니다. 와이어 제품은 제조사 자료에 근거한 시험 후보이고 양산 승인 여부는 사내 조건표와 실제 시험으로 판단합니다.

기존 Tkinter 화면은 보관용으로 남겨두었습니다. 필요하면 `python weld_gui.py`로 실행할 수 있습니다. PySide6 전환 테스트까지 확인하려면 `.\.venv\Scripts\python.exe -m unittest test_weld.py test_qt_gui.py -q`를 실행합니다.

## 기존 Tkinter 사용 설명

기존 Tkinter 화면에는 Python 3과 Tkinter가 필요하며, GUI 실행에 필요한 Tcl/Tk 리소스는 `runtime-tcl` 폴더에 포함했습니다. 기본 계산과 PNG·GIF 미리보기에는 외부 패키지가 필요하지 않습니다.

## 사용법

1. 차종·제품명과 설비·가스 정보를 입력합니다.
   제품 정보의 **제품 형상 이미지 첨부**로 PNG·JPG·GIF·BMP·WebP 이미지를 한 장 선택할 수 있습니다. 입력 화면과 결과 화면에 축소 미리보기가 표시되며, 이미지는 작업 폴더에 복사하지 않습니다. 원본 파일은 변경되지 않습니다. JPG·BMP·WebP 미리보기에는 Pillow가 필요하고, Pillow가 없으면 PNG·GIF를 사용할 수 있습니다.
2. 용접 구간을 추가하고 각 구간의 길이와 이동 속도 또는 시간을 입력합니다. 재질은 목록에서 고르거나 직접 입력할 수 있습니다. 같은 작업 단계 번호의 구간은 동시에 작업하는 것으로 계산하며, 번호가 다르면 단계별로 순서대로 작업합니다. 기본값은 구간마다 다른 번호입니다.
3. 한 사이클 생산 수량, 비아크 시간, 가동률, 근무 일정을 입력합니다.
4. **계산하기**를 누르면 결과 탭에 시간·UPH·생산량과 와이어 후보가 표시됩니다.

**결과** 탭은 `한눈에 보기`(주요 지표·기간별 생산량/전력량/와이어 사용량), `와이어 추천 제품`(구간·브랜드·품명·AWS 분류), `계산 근거·안내`로 나뉩니다. 추천 제품 행을 두 번 클릭하면 제조사 자료를 열 수 있습니다. **와이어만 추천**을 누르면 추천 제품 표가 바로 표시됩니다.

**사내 승인 조건** 탭에서 [사내승인조건_입력양식.csv](사내승인조건_입력양식.csv)에 맞춘 조건표를 첨부할 수 있습니다. 입력 탭의 재질 두 가지, 두께, 공정, 이음, 자세, 보호가스, 설비가 모두 일치하는 기록만 표시하며 **선택한 승인 조건 적용**을 눌렀을 때 전압·전류·이동 속도를 입력칸에 반영합니다. 조건표의 승인·개정·유효 상태는 사용자가 확인해야 합니다. 조건표는 외부 서비스로 업로드하지 않습니다.

전력량을 함께 보려면 각 용접 구간의 **전압(V)·전류(A)**, 공통 조건의 **용접기 효율(%)** 및 **비아크 설비 입력전력(kW)**을 입력합니다. 결과에는 용접 중·비아크·사이클당·제품 1개당·시간당·일·월·년 예상 소비 전력량(kWh)이 표시됩니다. 비아크 시간이 0초면 비아크 입력전력은 생략할 수 있습니다. 값이 부족해도 시간·생산량은 계산하고, 전력량에는 필요한 입력 항목을 안내합니다.

용접 중 전력량은 `Σ(전압 × 전류 × 구간 시간) ÷ (3,600,000 × 효율)`로 추정하며 효율은 0~1 비율로 사용합니다. 비아크 전력량은 `비아크 입력전력(kW) × 비아크 시간(초) ÷ 3,600`입니다. 가동하지 않는 시간의 대기전력, 조명·환기 등 주변 설비는 포함하지 않습니다. 실측 전력계 값으로 검증해야 합니다. 기존 CSV 형식도 불러올 수 있으며, 전력량용 열은 `voltage,current,efficiency,nonArcPower`를 선택적으로 추가합니다. `efficiency`와 `nonArcPower`는 첫 데이터 행에만 입력합니다.

두 부품의 재질만 알 때는 각 구간의 **부품 A 재질·부품 B 재질**만 선택하고 **와이어만 추천**을 누릅니다. 나머지 조건이 없으면 `재질 기반 예비 후보`로 표시하고 추가 확인할 정보를 나열합니다.

와이어 결과에는 KISWEL, KOWEL(코웰), ESAB, HYUNDAI의 공식 자료에서 AWS 분류가 맞는 기성품의 품명과 출처를 표시합니다. 제조사 자료에서 동일 분류를 확인하지 못한 경우에는 `동일 AWS 분류 제품 미확인`으로 표시합니다. 제품의 재고·국내 공급, 직경, 보호가스, 실제 이음 적용성은 별도 확인이 필요합니다. 제품 목록은 [wire_catalog.py](wire_catalog.py)에 있습니다.

**실측 검증** 탭에서는 같은 차종·제품의 사이클 시간을 여러 건 입력하고 기밀 검사·불량 여부를 기록할 수 있습니다. **실측값 비교**를 누르면 계산 사이클과 실측 평균의 차이, 오차율, 실측 평균 기준 UPH를 보여줍니다. 허용 오차율은 선택 입력이며 생산기술팀 기준을 사용해야 합니다. 실측값은 CSV로 저장·불러올 수 있습니다. [예시_실측값.csv](예시_실측값.csv)는 화면 확인용 가상 데이터입니다.

**와이어 사용량 (선택)** 탭에는 용접 구간별 사용 제품명, 직경(mm), 밀도(g/cm³), 평균 송급 속도(m/min)를 입력합니다. 실제 송급 길이(m/사이클)를 측정했다면 이를 우선 사용합니다. 실측 아크 시간, 추가 송급 길이, 절단·폐기량, 용착 효율, 단가도 구간별로 입력할 수 있습니다. 결과에 구간별 송급량과 사이클당·제품당·시간당·일·월·년 와이어 사용량을 표시합니다. 용착 효율 입력 시 예상 용착량을, 단가 입력 시 예상 비용을 별도로 보여줍니다. 용착 효율은 구매 소요량 자체를 줄이는 값으로 사용하지 않습니다.

시작·종료 와이어 잔량(kg)과 그 사이의 생산 사이클 수를 입력하면 저울 실측 사용량을 계산해 송급량 추정치와 비교합니다. 같은 용기 기준으로 계량하고, 중간에 와이어를 교체했다면 투입량을 반영해야 합니다. 추정 송급량은 `π × (직경/2)² × 송급 길이 × 밀도`로 g 단위이며, 입력하지 않은 추가 송급·폐기량은 포함하지 않습니다. 전류·전압은 송급량과 관계가 있지만 두 값만으로 송급량을 역산하지 않습니다. 기존 CSV 형식은 그대로 사용할 수 있으며 와이어 관련 열은 선택적으로 추가할 수 있습니다. 열 이름은 [wire_usage.py](wire_usage.py)의 `WIRE_ROW_FIELDS`, `WIRE_COMMON_FIELDS`를 참조하세요.

**예시값 불러오기** 또는 **CSV 파일 첨부**로도 입력할 수 있습니다. [예시_용접조건.csv](예시_용접조건.csv)를 형식 예제로 사용하세요. CSV는 UTF-8로 저장합니다. 한 행이 용접 구간 하나이고, 차종·제품명·설비·생산 조건 등 공통값은 첫 데이터 행에 적습니다.
CSV에 선택 열 `stage`를 추가하면 같은 번호의 구간을 동시 작업으로 계산합니다. 열이 없으면 각 행을 순차 작업으로 처리합니다.

와이어는 제조사 자료에 근거한 시험용 후보입니다. 직접 입력한 재질에 후보 규칙이 없으면 승인 조건표와 제조사 자료를 확인하도록 안내합니다. 총 아크 시간은 구간별 시간의 합계, 경과 용접 시간은 단계별 최장 시간의 합계입니다. 사이클 시간은 경과 용접 시간에 비아크 시간을 더하며, 생산량은 이 가정에 따른 미검증 추정치입니다.

실측 비교 결과 역시 용접 조건이나 생산능력을 자동 승인하지 않습니다. 기밀 불합격·불량 기록은 건수로 표시하고, 비아크 시간 참고값은 누락된 작업을 찾는 데 사용합니다.

검증: `python -m unittest test_weld.py -v`

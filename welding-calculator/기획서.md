# 용접 조건 추천 및 생산량 예측 프로그램 기획서

## 1. 주제와 목표

자동차 머플러 부품의 재질과 형상 등을 입력하면 용접 조건, 와이어, 용접 자세, 예상 용접 시간을 제시하고, 이를 바탕으로 UPH와 일·월·년 예상 생산량을 계산하는 프로그램을 만든다.

전체 목표는 다음 세 기능을 포함한다.

1. 검증된 용접 조건 검색 및 추천
2. 예상 용접 시간과 생산량 계산
3. 용접 와이어 추천과 추천 이유 표시

## 2. 현재 입력 자료

현재 보유한 용접 조건표, 도면, 와이어 목록, 실측 용접 시간 등의 자료는 없다. 따라서 첫 버전은 사용자가 값을 직접 입력하는 방식으로 만든다. 사내 검증 데이터가 확보되기 전에는 전압·전류·용접 속도·와이어를 확정된 양산 조건으로 자동 추천하지 않는다.

개발·시연에 쓰는 임의 데이터는 모두 **화면 확인용 예시 데이터**로 표시한다. 예시값은 사용자가 입력할 항목과 계산 흐름을 확인하기 위한 것이며, 실제 부품의 용접 조건이나 생산능력 근거로 사용하지 않는다. 화면을 처음 열었을 때 예시값을 보여주더라도 사용자가 자신의 값을 확인하거나 수정한 뒤에 계산을 실행하도록 한다.

입력값은 화면에서 직접 입력하거나 CSV 파일을 첨부해 불러올 수 있다. 차종과 제품명은 선택 입력이며 결과 화면에 표시한다. CSV는 한 행이 용접 구간 하나이며, 첫 데이터 행에 공통 생산 조건(`batch`, `nonArc`, `uptime`, `hours`, `days`, `months`), 제품 정보(`vehicle`, `productName`)와 용접 방식·설비·가스(`process`, `equipment`, `gas`)를 적는다. 필수 열은 `length`, `mode`, `speed`, `time`과 위 생산 조건이다. `mode`는 `speed` 또는 `time`이다. `speed` 모드에서는 `speed`를, `time` 모드에서는 `time`을 입력한다. 와이어 후보 검토용 열은 `materialA`, `thicknessA`, `materialB`, `thicknessB`, `joint`, `position`이다. 예시 파일은 `예시_용접조건.csv`로 제공하며 `dataType` 열의 `sample` 값으로 예시 데이터임을 표시한다. 첨부 파일은 계산 전에 전체 검증하고, 오류가 있으면 기존 입력을 유지한다.

## 3. 원하는 최종 결과

- 추천 용접 조건: 전압, 전류, 용접 속도
- 추천 와이어와 그 이유
- 권장 용접 자세
- 예상 용접 시간
- UPH(시간당 예상 생산량)
- 일·월·년 예상 생산량

용접 조건과 와이어 추천에는 근거 자료 및 검증 상태를 함께 표시한다. 신규 추천값은 실제 부품 시험과 품질 확인 후 양산 조건으로 승인한다.

현재 구현된 와이어 후보 기능은 두 부품의 재질·두께, 이음 형상, 자세, 용접 방식, 설비, 보호가스를 입력받는다. 현재 지원하는 규칙은 GMAW의 409/409Ti→ER409Nb, 304L/304L→ER308L 계열, 304/304→ER308 계열, 탄소강/304·304L→ER309LSi 사례이다. 각 후보에는 제조사 출처와 보호가스 확인 문구를 표시한다. 미지원 재질 조합이나 필수 정보 누락 시 후보를 표시하지 않는다. 사내 승인 조건표가 없어 전압·전류·와이어 송급 속도는 제시하지 않는다. 후보는 시편 시험용 검토 자료이며 양산 승인 조건이 아니다.

## 4. 처음 만들 기능: 용접 시간·UPH·생산량 계산기

### 사용자가 입력할 값

| 구분 | 입력값 | 단위·설명 |
|---|---|---|
| 용접 | 용접 구간별 길이 | mm/구간. 구간을 여러 개 추가 가능 |
| 용접 | 구간별 이동 속도 또는 직접 입력한 용접 시간 | mm/min 또는 초/구간 |
| 생산 | 한 사이클 생산 수량 | 개/사이클 |
| 부대 시간 | 준비·클램프·해제·부품 이동 등 비아크 시간 | 초/사이클 |
| 생산 | 가동률 | %, 계획 시간 중 실제 생산 가능 비율 |
| 생산 | 일일 근무시간 | 시간/일 |
| 생산 | 월간 가동일수 | 일/월 |
| 생산 | 연간 가동 개월 수 | 개월/년 |

여러 용접 구간을 추가할 수 있으며 각 구간은 이동 속도로 시간을 계산하거나 용접 시간을 직접 입력한다. 같은 작업 단계 번호의 구간은 동시에 용접하고, 다른 단계는 순서대로 작업한다고 가정한다. 기본값은 구간마다 다른 단계 번호다. 병렬 설비 수와 불량률은 계산 범위에 포함하지 않는다.

### 계산식

- 구간별 용접 시간(초) = 구간 길이(mm) ÷ 구간 이동 속도(mm/min) × 60, 또는 직접 입력한 시간
- 총 아크 시간(초/사이클) = 각 구간 용접 시간의 합
- 경과 용접 시간(초/사이클) = 단계별 최장 용접 시간의 합
- 예상 사이클 시간(초/사이클) = 경과 용접 시간 + 비아크 시간
- UPH(개/시간) = 3,600 ÷ 예상 사이클 시간 × 한 사이클 생산 수량 × 가동률
- 일 예상 생산량(개) = UPH × 일일 근무시간
- 월 예상 생산량(개) = 일 예상 생산량 × 월간 가동일수
- 년 예상 생산량(개) = 월 예상 생산량 × 연간 가동 개월 수

가동률은 0~100%로 입력한다. 생산량 화면에는 계산값과 함께 입력값·계산식을 표시한다. 생산량의 소수값은 내부 계산에 유지하고, 표시할 때는 정수 개수로 내림 처리한다. 생산량은 입력 가정에 따른 **계획용 추정치**이며 실측 택타임이나 확정 생산능력을 뜻하지 않는다.

결과 화면에는 `예시 데이터로 계산` 또는 `사용자 입력으로 계산` 상태를 눈에 띄게 표시한다. 예시 데이터의 결과에는 **양산 조건·확정 생산능력으로 사용 불가** 문구를 함께 표시한다.

### 실측 시간 검증 및 보정

1. 실제 부품·설비·작업 조건별로 용접 시간과 총 사이클 시간을 여러 차례 측정하고, 측정일·품번·설비·작업 조건을 기록한다.
2. 계산된 아크 시간 및 사이클 시간과 실측값을 비교한다. 차이가 나는 구간을 접근·자세 변경·클램프·부품 이동·검사 등으로 나눠 누락된 비아크 시간을 확인한다.
3. 같은 조건에서 반복 측정한 값의 대표값을 비아크 시간 입력 기준으로 반영한다. 단일 측정값이나 임의 보정계수만으로 기준을 확정하지 않는다.
4. 품번·설비·공정이 바뀌면 기존 보정값을 그대로 적용하지 않고 다시 확인한다. 허용 오차와 기준값 승인 여부는 생산기술팀이 정해 기록한다.
5. 검증 전 결과는 `미검증 추정`, 실측 비교와 담당자 승인을 마친 결과는 `실측 검증`으로 구분한다. 실측 검증 상태라도 생산량은 입력한 가동률과 근무일정에 따른 계획값으로 표시한다.

## 5. 첫 기능의 완료 기준

1. 사용자가 용접 구간을 추가·삭제하고 각 구간별 길이와 이동 속도 또는 용접 시간을 입력할 수 있다. 한 사이클 생산 수량, 비아크 시간, 근무시간, 가동률, 월간 가동일수, 연간 가동 개월 수도 입력할 수 있다.
2. 입력 후 아크 시간, 사이클 시간, UPH, 일·월·년 예상 생산량이 자동 계산된다.
3. 결과 화면에서 사용한 입력값과 계산 근거를 확인할 수 있다.
4. 구간별 용접 길이·선택한 이동 속도 또는 용접 시간·근무시간·가동일수·가동 개월 수는 0보다 커야 한다. 한 사이클 생산 수량은 1 이상의 정수, 비아크 시간은 0 이상, 가동률은 0~100%만 허용한다. 잘못된 입력은 수정 안내를 표시하며, 가동률 0%일 때 생산량은 0으로 표시한다.
5. 입력값을 바꾸면 결과가 다시 계산된다.
6. 예시값과 사용자 입력값의 출처가 구분되고, 예시값 결과에는 양산 사용 불가 문구가 표시된다.
7. 결과에 `미검증 추정` 상태가 기본 표시되며, 실측 시간·조건·담당자 승인 기록이 없는 결과를 `실측 검증`으로 표시할 수 없다.
8. CSV 파일 첨부로 여러 구간과 생산 조건을 불러오고 계산할 수 있다. 잘못된 파일은 오류를 안내하며 기존 입력을 변경하지 않는다.

## 6. 이후 확장에 필요한 자료

조건 및 와이어 추천 기능을 구현할 때는 부품 재질·두께·형상·이음 형태, 사용 설비와 가스, 기존 승인 조건, 와이어 규격, 기밀·외관·치수 검사 결과, 실제 사이클 시간 데이터를 확보한다. 이 자료를 기반으로 적용 가능한 승인 조건을 우선 검색하고, 유사 사례의 후보 조건은 별도로 표시한다.

## 7. Python GUI 구현

`weld_gui.py`에서 차종·제품명, 여러 용접 구간, CSV 첨부, 시간·UPH·생산량 계산, 제조사 자료 기반 와이어 후보를 제공한다. 계산과 후보 규칙은 `weld_core.py`에 분리했다. `용접계산기_실행.cmd`로 GUI를 실행할 수 있다. 현재 전압·전류·와이어 송급 속도는 사내 승인 데이터가 없어 표시하지 않는다. 제품 이미지 자동 판독은 이번 GUI 범위에 포함하지 않았다.

재질 정보 두 가지만 입력해 와이어 예비 후보를 확인하는 `와이어만 추천` 기능을 제공한다. 실측 검증 탭에서는 동일 제품의 반복 측정 사이클 시간과 기밀·불량 결과를 기록하고, 계산값 대비 실측 평균 오차와 허용 오차 범위 여부를 확인한다. 실측 자료는 CSV로 저장·불러올 수 있다. 오차와 품질 결과는 검토 자료이며 자동 양산 승인을 의미하지 않는다.

제조사 제품 표시는 KISWEL, KOWEL(코웰), ESAB, HYUNDAI의 공식 자료에서 제품명과 AWS 분류를 대조한 경우에만 제공한다. 409/409Ti의 ER409Nb는 KISWEL·ESAB 제품만 확인했으며 KOWEL·HYUNDAI의 다른 분류 제품을 대체품으로 자동 표시하지 않는다. 모든 제품은 구매 가능 여부, 와이어 직경, 보호가스, 시편 성능, 사내 승인 조건을 확인한 뒤 적용한다.

제품 정보에는 형상 이미지 한 장을 선택해 입력·결과 화면에서 미리볼 수 있다. 작업 폴더에 사본을 만들지 않는다. 부품 재질은 목록에서 선택하거나 직접 입력한다. 후보 규칙이 없는 재질은 와이어를 자동 추천하지 않는다. 이미지 파일만으로 용접 위치·자세·조건을 판독하거나 추천값을 변경하지 않는다.

전력량 추정에는 구간별 용접 전압·전류와 설비 효율, 비아크 설비 입력전력을 별도로 입력한다. 용접 출력 전력(V×A)을 효율로 나눠 입력 전력량을 추정하고, 비아크 시간에 대한 입력전력을 더한다. 사이클당·제품당 및 예상 생산량에 따른 시간·일·월·년 전력량을 표시한다. 필요한 값이 없으면 합계를 계산하지 않고 누락 항목을 안내한다. 실제 전력계 측정 및 사내 설비 기준으로 검증하기 전에는 계획용 추정치로만 사용한다.

와이어 사용량은 선택 탭에서 구간별로 입력한다. 와이어 제품명, 직경, 밀도, 평균 송급 속도 또는 실측 송급 길이, 실측 아크 시간, 추가 송급 길이, 절단·폐기량, 용착 효율, 단가를 기록한다. 송급 와이어 질량과 절단·폐기량을 합산해 구매 소요량을 추정하고, 용착 효율은 용착량 계산에만 적용한다. 시작·종료 와이어 잔량과 생산 사이클 수가 있으면 실제 사용량을 산출해 추정값과 차이를 표시한다. 필요한 값이 없으면 총 추정치를 표시하지 않는다. 전류·전압으로 송급 속도를 자동 추정하지 않는다.

보안상 도면 파일 첨부와 OCR 읽기 기능은 제공하지 않는다. 부품 재질·두께·공정·이음·자세는 사용자가 입력한다. 전압·전류·이동 속도는 실제 사내 승인 조건 CSV가 있을 때 재질·두께·공정·이음·자세·가스·설비가 모두 일치하는 기록만 제시하고, 사용자가 선택했을 때만 적용한다.

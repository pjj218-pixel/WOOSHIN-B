# PySide6 화면 전환 및 GitHub 보관 설계

## 목적과 범위

현재 Windows용 용접 계산기의 Python GUI 기능을 PySide6로 이전한다. 사용자는 기존과 같이 한 제품의 차종·제품명, 여러 용접 구간, 설비·생산 조건을 입력하고 결과를 확인한다. 현재 소스, 기획서, 예시 CSV, 테스트, 레거시 화면과 실행 리소스는 사용자가 지정한 GitHub 저장소 `pjj218-pixel/WOOSHIN-B`에 보관한다.

기능 추가나 용접 추천 규칙 변경은 이번 전환 범위에 포함하지 않는다. 계산 결과는 기존 Python 코어가 반환하는 값과 일치해야 한다. 와이어 추천은 시험 후보이며 사내 승인 조건 또는 실측 검증과 혼동되지 않도록 상태를 표시한다.

## 선택한 접근

PySide6 Qt Widgets로 Windows 데스크톱 화면을 다시 만든다. 기존 `weld_core.py`, `wire_catalog.py`, `wire_usage.py`, `approved_wps.py`, `validation_core.py`를 계산·검증 코어로 재사용한다. 기존 `weld_gui.py`와 웹 시제품 파일은 보관하되 새 실행 경로에서 불러오지 않는다. 화면의 입력 수집과 결과 표시만 새 GUI에 둔다.

CustomTkinter는 화면 변경량이 적지만 복잡한 표·입력 흐름에 제약이 있다. NiceGUI는 브라우저/로컬 서버 운영 방식이 필요하다. 현재 한 PC의 Windows 앱을 현대화하는 목표에는 PySide6가 맞는다.

## 화면과 데이터 흐름

새 화면은 왼쪽 메뉴 또는 상단 탐색으로 `작업 조건`, `결과`, `사내 승인 조건`, `와이어 사용량`, `실측 검증`을 이동한다. 작업 조건은 제품 정보·형상 이미지 미리보기, 공통 생산 조건, 추가/삭제 가능한 용접 구간으로 구성한다. 결과는 주요 수치를 카드로 요약하고 기간별 생산량·전력량·와이어 사용량 표, 구간별 근거, 브랜드별 와이어 후보를 분리한다. 제조사 자료 링크와 예시/미검증 상태를 결과 가까이에 표시한다.

화면 입력을 기존 코어의 `normalize_plan` 입력 형식으로 변환하고 `calculate`, `calculate_energy`, `recommend_wire`, `calculate_wire_usage`에 전달한다. CSV 입력·실측 CSV 저장·승인 조건 CSV 검색은 기존 형식을 유지한다. 승인 조건 적용 시 선택된 구간의 전압·전류·속도만 명시적으로 갱신한다. 제품 이미지는 기존과 같이 로컬 미리보기만 제공하고 자동 판독하거나 업로드하지 않는다.

## 오류 처리와 경계

숫자·필수 항목 오류는 해당 입력 화면과 메시지에 표시한다. CSV는 전체 검증 후 한꺼번에 반영하여 실패 시 현재 입력을 유지한다. 선택 입력이 부족하면 시간·생산량 계산과 별개로 전력·와이어 사용량의 누락 항목을 안내한다. 미지원 재질 조합에는 임의 제품을 표시하지 않는다. 이미지 파일 접근 실패는 계산을 막지 않는다.

## GitHub 보관과 배포

첫 커밋 전에 파일 목록과 민감 자료를 확인한다. `__pycache__`, 가상환경, 생성된 실행 파일, 개인 제품 이미지는 제외한다. 기존 소스·문서·예시 자료와 Tkinter 실행에 필요한 `runtime-tcl`은 보관한다. 원격 저장소 `master`에는 이미 별도의 출장 경비 정산 프로젝트가 있으므로 용접 계산기를 `welding-calculator/` 하위 폴더에 통합한다. 기존 기록과 루트 파일은 덮어쓰지 않고 강제 푸시는 하지 않는다. 로컬 작업 폴더의 루트 구조는 유지한다. PySide6 설치 방법과 새 실행 명령을 README에 기록한다. 설치형 실행 파일 제작은 이번 범위에 포함하지 않는다.

## 완료 기준

1. 기존 Python GUI의 입력, 결과, 승인 조건, 실측 검증, 와이어 사용량, 제품 이미지 미리보기 흐름을 새 화면에서 사용할 수 있다.
2. 예시 한 건과 CSV 한 건에서 기존 코어와 동일한 주요 수치·와이어 후보를 확인한다.
3. 기존 코어 테스트가 통과하고 PySide6 화면의 주요 흐름을 실행해 확인한다.
4. 새 실행 방법과 기존 Tkinter 실행 방법이 문서화된다.
5. GitHub 원격 저장소에 원본 보관 커밋과 PySide6 전환 커밋이 반영된다.
